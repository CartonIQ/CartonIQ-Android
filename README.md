📦 CartonIQ — Android App

Smart packaging calculations and box design for the corrugated packaging industry.

CartonIQ is an Android application designed to simplify packaging calculations, box design, and quotation workflows.

✨ Features

- 📐 Industrial Calculator — FEFCO box styles, paper costing, and margin calculations.
- 🧊 3D Box Designer — Visualize box dimensions in 3D.
- 🧾 Quotations & Orders — Create professional PDF quotations with custom branding.
- 🖨️ Printing — Print supported documents from the app.
- 🔒 Local Data — Designed with an offline-first approach.

🛠️ Technology Stack

- React
- Vite
- Capacitor
- Tailwind CSS
- Android native printing integration

📱 About

Built with a mobile-first development workflow using Termux and Android development tools.
